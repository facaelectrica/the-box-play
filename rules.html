Separate feature: cracking mode

An on/off button. These rules sit outside the ranking above.

  • He's damaged by how hard he hits. Below 2.8 m/s there's no damage (hands and feet: 4.2 m/s). Damage adds up, and a part breaks when it's had enough.
  • Feet and hands used as support while standing never crack, and nothing counts during a get-up.
  • Wood sound; branching cracks with chips; dent marks on the box. Broken pieces keep moving and can split further.
  • No freeze when he breaks. If the head, neck or trunk breaks, he stops.

How a new request joins

  1. It gets a place in the ranking: it either becomes a new rule or is added to an existing one.
  2. Clashes are written down in the table above, with which rule wins and how.
  3. One piece of code owns it and gets a test that measures it.
  4. It's built, tested against all the rules, and released. This page is updated with the build.

Source: the project doc "rulebook-test-page.md". Live copy next to the game: facaelectrica.github.io/the-box-play/rules.html. Every agent updates it with each build.
